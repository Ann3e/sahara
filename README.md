# 🌵 Sahara – Voice-First DSA & Mock Interview Assistant

**Sahara** is an AI-powered interview prep and DSA tracker platform that lets users speak their thoughts and track their journey visually and verbally. Designed to enhance technical interview prep by combining **AI feedback**, **voice recording**, and **DSA progress tracking**.

---

## 🚩 Core Features

### 🎯 1. DSA Tracker  
- Track solved/unsolved problems topic-wise  
- Add notes or voice explanations  
- Mark progress as you complete topics  

### 🎤 2. Voice-First Explanations  
- Use your **microphone** to record answers and notes  
- Audio is transcribed and stored  
- Recordings are saved securely to **Cloudinary**  

### 🤖 3. AI-Powered Mock Interviews  
- Generate intelligent coding/system design questions using **Gemini API**  
- Submit text or voice answers  
- Get structured AI **feedback**  

### 🔐 4. Authentication & Authorization  
- **JWT-based auth** for protected routes  
- **bcrypt** for password hashing  
- Secure **login/register** system  
- Auth middleware for protected features
